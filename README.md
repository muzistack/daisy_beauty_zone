# Daisy Beauty Zone — Frontend Website

A responsive beauty parlour website starter built with HTML5, CSS3 and JavaScript.

## Files
- `index.html` — home page, service menu, about section, gallery, reviews placeholders and appointment enquiry form
- `style.css` — responsive blush pink, cream and plum styling
- `script.js` — mobile navigation, service preselection, date minimum and demo enquiry form
- `assets/` — add the salon's own images and approved media here

## Preview
Extract the ZIP and open `index.html` in a modern browser. Internet access is needed for the remote Unsplash sample images and Google Fonts.

## Before publishing
1. Replace sample/inspiration photos with Daisy Beauty Zone's own licensed images.
2. Replace service descriptions with the salon's actual services, prices and policies.
3. Add the verified salon email in `script.js` as `SALON_EMAIL`. Without this, the form only displays a local enquiry preview and does not send or book anything.
4. Add the actual address, phone, opening hours, WhatsApp and social links once verified.
5. Replace review placeholders with genuine customer reviews shared with permission.
6. Connect the form to a backend or booking service if you want submissions stored reliably.

This is a frontend project. It does not include a backend, payment system or live booking integration.
